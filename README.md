# Zone Ten

A mobile-first light meter for film photographers. It's set up for a **Pentax LX**, **Canon AE-1 Program** and
**Yashica A**, and any other camera you add. It measures light from your phone's camera, then recommends only
apertures and shutter speeds your camera can actually set. It shows the metered exposure, the closest camera
setting and the error in stops side by side, and adds film-aware reciprocity correction.

React 19 · TypeScript (strict) · Tailwind CSS 4 · Vite · Vitest. Offline-first PWA; all data stays on the device.

## Run

```bash
npm install
npm run dev          # local dev server
npm test             # exposure engine tests
npm run build        # production build → dist/
npm run build:single # one self-contained HTML file → dist-single/index.html
```

## On your phone

Published with GitHub Pages at **https://analog-desk.github.io/zone-ten/**. It installs like an app and works offline
after the first visit.

* **iPhone (Safari):** open the link → Share → *Add to Home Screen*.
* **Android (Chrome):** open the link → ⋮ → *Install app*.

To publish a new version: `npm run deploy` (runs the tests, builds the single-file app, pushes it to `gh-pages`).
One-time setup: *Settings → Pages → Deploy from a branch → `gh-pages` / root*.

## How it measures

| Path | Works on | How |
| --- | --- | --- |
| **Photo meter** (Measure button) | iPhone + Android | Reads the photo's EXIF exposure (time, f-number, ISO) and the linearised pixels of the metered area. Tap the photo to spot meter. |
| **Live meter** | Browsers that expose manual camera exposure (Chrome on Android) | Drives exposure time/ISO so the metered area sits near mid-grey and reads the values back each frame. On iPhone Safari the live view is for framing only. |
| **Incident** | Only with a registered diffuser accessory + consistent calibration | Locked otherwise — a phone camera alone is not an incident meter. |

`EV₁₀₀ = log₂(N²/t) − log₂(ISO/100) + log₂(Y/0.18) + calibration`. The phone's auto-exposure only decides where the
picture sits; the reading comes from the pixels and metadata. Readings far from the phone's own exposure, clipped,
or below the noise floor are flagged. **Readings are uncalibrated until you compare against a reference meter**
(Settings → Calibration; offsets in 0.1-stop steps, one profile per path). See `docs/MEASUREMENT.md`.

## Structure

| Module | What it holds |
| --- | --- |
| `src/engine/` | UI-independent engine: scales (exact vs engraved values), exposure maths, camera-aware solver (locks/modes, closest valid setting, alternative, explanation), goals & creative suggestions, film catalog/reciprocity/Rate My Film, measurement model, calibration, Zone System and film tools |
| `src/engine/__tests__/` | 64 tests: maths, scales, all three camera profiles, solver constraints, reciprocity, catalog, measurement, calibration |
| `src/data/film_catalog.json` | Versioned film catalog (generated by `scripts/build_catalog.py`) |
| `src/lib/` | Photo meter (EXIF + pixels), live meter (MediaStream manual exposure), PDF reports |
| `src/state/` | IndexedDB persistence (one versioned JSON document + reference images), actions, derived state |
| `src/screens/` | Onboarding (6 steps → meter), Meter, Profiles, Film Library, Film Tools, Sessions, Settings |

Docs: `docs/DATABASE.md`, `docs/MEASUREMENT.md`, `docs/FILM_CATALOG.md`, `docs/TESTING.md`.
